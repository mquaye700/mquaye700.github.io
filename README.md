# mquaye700.github.io

This repository hosts the static personal website for Michael Quaye.

## Live Site
The site is ready to deploy with GitHub Pages from the repository root.

## Files
- `index.html` — main homepage content
- `styles.css` — site styling
- `script.js` — mobile navigation support

## Customize
Update the text in `index.html` to personalize your about section, projects, and contact link.

## Deploy
1. Push this repository to GitHub.
2. Go to repository **Settings > Pages**.
3. Choose the `main` branch and set the folder to `/ (root)`.
4. Save and visit the published URL.
